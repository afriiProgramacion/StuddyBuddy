# StuddyBuddy

Una plataforma para que estudiantes organicen sus asignaturas, apunten tareas y compartan apuntes.  
Tiene registro y login, un panel con las asignaturas del usuario, tareas con fecha de entrega y estado, y apuntes compartidos con comentarios. 
Es lo bastante grande para un mes y toca las cuatro tecnologías del stack.
